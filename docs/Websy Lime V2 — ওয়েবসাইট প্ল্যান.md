**হেডারের অ্যাডভান্স ফিচার:**

## ৬. ডিজাইন পরামর্শ

- **ব্র্যান্ড কালার:** নামেই "Lime" আছে। ডার্ক বা অফ-হোয়াইট ব্যাকগ্রাউন্ডে লাইম গ্রিন অ্যাকসেন্ট প্রিমিয়াম দেখায় ও মনে থাকে।
- **টাইপোগ্রাফি:** হেডলাইনে বড়, বোল্ড ফন্ট (Clash Display, Satoshi, General Sans), বডিতে Inter বা Geist।
- **অ্যানিমেশন নিয়ে সতর্কতা:** বেশি অ্যানিমেশনে সাইট ধীর হয়। US লোকাল বিজনেস মালিকরা বেশিরভাগ মোবাইলে দেখেন, তাই মোবাইলে অ্যানিমেশন হালকা রাখুন। Google PageSpeed স্কোর ৯০+ রাখার লক্ষ্য রাখুন।
- **নিজের সাইটই সবচেয়ে বড় পোর্টফোলিও:** ক্লায়েন্ট আপনার সাইট দেখেই আপনার কাজের মান বিচার করবে।

## ৮. কনটেন্ট স্ট্র্যাটেজি ও লেখার টোন

মূল বার্তা: **ক্লায়েন্ট শুধু তার ব্যবসা চালাবে, অনলাইনের সব কাজ (ওয়েবসাইট, সোশ্যাল প্রেজেন্স, গ্রোথ) এক টিমের কাছে, কোনো ঝামেলা ছাড়াই।**

**লেখার নিয়ম:**

- আগে ক্লায়েন্টের সমস্যা, তারপর আমাদের সমাধান। নিজেদের নিয়ে কম, ক্লায়েন্টের লাভ নিয়ে বেশি
- হেডলাইন ৩–৮ শব্দ, সাবটেক্সট সর্বোচ্চ ২০ শব্দ, কার্ডের লেখা ১–২ লাইন
- "You/Your" বেশি, "We" কম
- ফিচার নয়, ফলাফল: "5-page website" এর বদলে "A website that books jobs while you work"
- জার্গন নয়: SEO, CTR, funnel এর মতো শব্দ ক্লায়েন্টের সামনে কম
- টোন: আত্মবিশ্বাসী, উষ্ণ, সংক্ষিপ্ত। হাইপ নয়

**মূল ট্যাগলাইন অপশন:**

- Websites that turn visitors into buyers.
- Your entire online presence. One team.
- You run the business. We run everything online.

**সততার নিয়ম:** স্পট-লেফট সংখ্যা, স্টার রেটিং, ক্লায়েন্ট সংখ্যা, টেস্টিমোনিয়াল ও স্ট্যাটস সব বাস্তব হতে হবে। নিচের কপিতে `[ ]` ব্র্যাকেটের জায়গাগুলো আসল তথ্য দিয়ে ভরতে হবে।

**প্রাইসিং-এর নিচে স্পেশাল কোট কার্ড:**

> **Every project gives back.** 2% of everything we earn goes to charity. When you grow with us, you help someone else grow too.

**কার্ডের ডিজাইন:** প্রাইসিং কার্ডগুলোর নিচে ফুল-উইডথ কার্ড, ডার্ক ব্যাকগ্রাউন্ডে লাইম গ্রিন বর্ডার বা হালকা গ্লো, বাম পাশে ছোট হার্ট বা পাতার আইকন, বড় "2%" সংখ্যাটা স্ক্রলে কাউন্ট-আপ হবে।

## ১২. Claude Code-এর জন্য বিল্ড নির্দেশনা

এই পুরো ডকটা Claude Code-কে দিয়ে নিচের প্রম্পট দিন। ধাপে ধাপে, প্রতিটা সেকশন রিভিউ করে এগোবেন।

**শুরুর প্রম্পট (কপি করে দিন):**

```markdown
Build the Websy Lime v2 marketing website from this spec.
Stack: Next.js (App Router) + TypeScript + Tailwind CSS + shadcn/ui, Motion for UI animation, GSAP + ScrollTrigger for scroll animation, Lenis for smooth scroll, Embla for carousels.
Put ALL copy in one file (content/site.ts) so text can be edited without touching components. Keep every [placeholder] visible and list them in a TODO.md.
Build one section at a time, starting with the header + mega menu, then the Hero. Stop after each section so I can review it.
```

**নিয়মগুলো:**

1. **কন্টেন্ট আলাদা:** সব লেখা `content/site.ts`-এ, কম্পোনেন্টে কোনো হার্ডকোড লেখা নয়
2. **ডিজাইন টোকেন:** কালার, ফন্ট, স্পেসিং Tailwind config-এ একবার ডিফাইন। লাইম গ্রিন অ্যাকসেন্ট, ডার্ক ও লাইট দুই মোড
3. **কম্পোনেন্ট ভাগ:** প্রতিটা সেকশন আলাদা ফাইল (`components/sections/Hero.tsx` ইত্যাদি)
4. **অ্যানিমেশন:** `prefers-reduced-motion` মানতে হবে, মোবাইলে ভারী অ্যানিমেশন বন্ধ বা হালকা
5. **পারফরম্যান্স:** Lighthouse মোবাইলে ৯০+, ছবি `next/image` দিয়ে, ফন্ট `next/font` দিয়ে
6. **রেসপন্সিভ:** মোবাইল আগে, তারপর ট্যাবলেট ও ডেস্কটপ
7. **SEO:** প্রতিটা পেজে মেটা টাইটেল, ডেসক্রিপশন, OG ইমেজ, সাইটম্যাপ
8. **অ্যাক্সেসিবিলিটি:** কিবোর্ড দিয়ে মেগা মেনু চালানো যাবে, ছবিতে alt টেক্সট
9. **পোর্টফোলিও ও টেস্টিমোনিয়াল:** ডেটা ফাইল থেকে আসবে, পরে CMS-এ সরানো যাবে

**বিল্ডের ক্রম:**

1. প্রজেক্ট সেটআপ, ডিজাইন টোকেন, ফন্ট
2. হেডার + মেগা মেনু + ফুটার
3. হোমপেজ, সেকশন ১ থেকে ১৪ পর্যন্ত একটা একটা করে
4. সার্ভিস পেজ, Pricing, Work, About, Submit a Project
5. অ্যানিমেশন পলিশ, পারফরম্যান্স ও মোবাইল টেস্ট
6. Vercel-এ ডিপ্লয়
